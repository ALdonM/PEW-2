# part190 — amplitude de la porteuse sans masse : le profil ρ(r)−1 autour du nœud passe-t-il de r^-4 à 1/r ?
Idée (M. Aldon) : la porteuse n'est pas une onde bouclée, donc sans masse ; seules les ondes bouclées ont une masse. Dans le modèle, la masse de l'amplitude vient du potentiel V = μ²(ρ²+1/(ρ²+d2)−2), m = 2√2 μ (≈0,75 pour μ=0,375). On la réduit : μ = 0,375 (référence), 0,1, 0,05, 0,02 (m = 1,06 / 0,28 / 0,14 / 0,057). μ=0 exact exclu : le vide ρ=1 ne serait plus sélectionné et le mur en 1/ρ² disparaîtrait avec lui.
Protocole : nœud part179 plongé au centre d'une boîte 96³ (h=0,5, L=48) de vide, couplage CP=1, friction 0,5, dt=0,005, t=40, relaxation seule (pas de houle).
Mesures (script analyse_part190.py) : (a) profil ρ(r)−1 par couches ; pente log-log locale pour r=6–20 ; ajustement ρ∞ + A/r ; (b) charge de Hopf conservée ; (c) vérification de la convergence (rms de la force / variation de ρ entre t=32 et 40).
Prédictions écrites avant les résultats [P] : (1) μ=0,375 : pente ≈ −4 (comme part179b / part189). (2) Quand m·r ≪ 1 (m≤0,14, r≤7), la pente locale s'adoucit vers −1 sur r=6–15 ; pour m=0,057 elle est ≈ −1 à −2. (3) Dans une boîte périodique l'amplitude moyenne se décale (la source monopolaire n'est pas neutralisable) : l'ajustement ρ∞ + A/r est nécessaire. Réfutation : pente ≤ −3 pour tous les μ sur r=6–15 (alors le profil r^-4 est d'origine géométrique de la source, pas de la masse), ou nœud instable (charge perdue). Réserves attendues : relaxation lente des modes sans masse (t=40 peut ne pas suffire), images périodiques à r>16, dt=0,005 non comparé à 0,0025.
