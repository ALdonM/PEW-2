# README part188 — « iceberg dans la houle » : une houle traverse un nœud, retard et déformation selon la distance de passage — STATUT : lancé le 19/11/2026

Idée (M. Aldon, 19/11) : la gravité = déformation de la porteuse par interférence avec les ondes bouclées, gardée « en mémoire » à longue portée ; G = capacité de l'onde à se déformer.
Question testée : dans le modèle Z, la perturbation d'une houle par un nœud a-t-elle une portée courte (exponentielle, longueur ≈ 2,4 d'après part187) ou longue (≈ 1/b) ?
Deux houles : (a) « phase » : Z → e^{iχ} Z, mode de Goldstone U(1), sans masse, énergie ∝ ρ²(∂χ)² ; (b) « amp » : δρ, mode d'amplitude, gap ≈ 2μ = 0,75 (ω² = k² + 4μ²).
Attendu AVANT le calcul, d'après le Lagrangien (temps et espace du terme de phase ont le même coefficient ρ²) : la houle de phase va à c = 1 partout ; ρ(x) ne change que l'impédance (diffusion), pas la vitesse. Donc retard de phase ≈ 0 au premier ordre, hors diffusion. Pour (b) : réfraction localisée là où ρ ≠ 1 (portée ≈ 2,4). Protocole : 64³, h = 0,5 (L = 32, nœud wk_T0 au centre), paquet gaussien (σ = 3, k = 1, ε = 0,1 ; 0,05 pour la linéarité) parti de x = −10 vers +x, sans friction, t = 22. Runs : K0 (nœud seul), Kp, Kp05 (nœud + houle de phase), Vp, Vp05 (vide + houle de phase), Ka (nœud + amp), Va (vide + amp). Signal S_K = φ(K+houle) − φ(K0), S_V = φ(V+houle) − φ(vide) ; par colonne transverse (y, z), position du centre de |S|² le long de x → Δx(b), b = √(y²+z²), comparée entre K et V.
Critères écrits avant : (1) résolution : écart Vp vs Vp05 (linéarité) et dispersion de réseau, Δx du témoin ; un décalage < 3 × résolution n'est pas rapporté ; (2) (a) : Δx(b) consistant avec 0 pour b ≥ 8 → pas de retard de type gravité ; sinon ajustement exponentiel vs puissance sur b = 4–14 ; (3) (b) : longueur de décroissance vs 2,4 ; (4) énergie diffusée (partie hors paquet) en fonction de b.
Résultat négatif possible et informatif : aucune queue longue → il faudra un secteur porteuse sans masse couplé aux nœuds (décision de modèle avec M. Aldon).
Limites : boîte périodique L = 32 (images à 32, b ≤ ~14 utile), un seul nœud, un seul k, un seul h ; le nœud de départ est le champ float16 de part179 (légère relaxation commune à K0 et K+houle, annulée par la soustraction) ; houle d'amplitude non strictement linéaire.
